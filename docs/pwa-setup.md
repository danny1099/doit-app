# PWA Configuration

This document describes the Progressive Web App (PWA) implementation in the Doit app.

## Features

- ✅ Offline support with service worker
- ✅ Install prompt for mobile and desktop
- ✅ Update notifications using Sileo toaster
- ✅ Optimized caching strategies
- ✅ App icons for all devices
- ✅ Multi-language support (EN/ES)

## Implementation Details

### Service Worker

The service worker is automatically generated by `@ducanh2912/next-pwa` and includes:

- **CacheFirst** strategy for fonts and images (long-term cache)
- **StaleWhileRevalidate** for static resources (JS/CSS)
- **NetworkFirst** for API calls with 10s timeout

Configuration is in `next.config.ts`.

### Manifest

Location: `/public/manifest.json`

Includes:
- App name and description
- Icons in 8 sizes (72px to 512px)
- Display mode: standalone
- Theme colors for light/dark mode

### Update Notifications

Component: `src/shared/components/pwa-update-prompt.tsx`

Listens for service worker updates and shows a toast notification using the project's Sileo toaster when a new version is available.

Translations are in:
- `src/lib/i18n/locales/en.json`
- `src/lib/i18n/locales/es.json`

Under the `pwa` key.

### Icons

Icons are generated from `/public/images/app-logo.svg` in 8 sizes:

- 72x72, 96x96, 128x128, 144x144
- 152x152, 192x192, 384x384, 512x512

To regenerate icons:

```bash
bun run generate:icons
```

## Testing

### Development

PWA features are disabled in development mode. To test:

```bash
bun run build
bun run start
```

Then visit `http://localhost:3000` in Chrome/Edge.

### Install Prompt

1. Build and run production mode
2. Open DevTools → Application → Service Workers
3. Check "Update on reload" during testing
4. Use "Add to Home Screen" in browser menu

### Offline Mode

1. Open DevTools → Network
2. Set throttling to "Offline"
3. Reload the page - app should still work
4. Check cached resources in Application → Cache Storage
