# Forms and Modals

## Modal

Use when:

- 3 fields or less
- Quick contextual actions

## Dedicated Page

Use when:

- More than 3 fields
- Complex workflows
- Multiple sections

## Rules

- Avoid scrolling inside modals
- Always provide cancel actions
- Sticky save actions on large forms
- Always provide clear feedback on form submissions
- Use ui desing system with tokens in global.css and use components shared in @shared/components
